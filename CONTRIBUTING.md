# Contributing

Use a fresh local database and synthetic examples. Never attach real household data or credentials.

Run the backend and frontend tests, a production frontend build and `node scripts/check-public.mjs` before opening a pull request. Include a short explanation of the user-visible change and relevant validation. Preserve integer-cent totals, archived category history, the final active administrator, keyboard accessibility and DD/MM/YYYY date handling.

By contributing, you agree that your contribution is available under the project's MIT license.
